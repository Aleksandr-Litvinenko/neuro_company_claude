# NEUROCORP — архитектура нейрокомпании

> Компания из одного человека (ты), которая работает как штат из 10–20+ «сотрудников».
> Все «сотрудники» — это нейроагенты и автоматизации. Ты — **man-in-the-middle**:
> система всё делает сама, но ключевые решения проходят через твой «стол одобрений».

---

## 1. Принцип: man-in-the-middle

```
            ┌───────────────────────────────────────────────┐
            │                 ТЫ (Оператор)                  │
            │   видишь всё в реальном времени на панели,      │
            │   принимаешь решения на «Столе одобрений»       │
            └───────────────────────────────────────────────┘
                      ▲ approve / reject / edit ▲
                      │                          │
   low-risk auto ─────┼── ПОЛИТИКА ОДОБРЕНИЙ ────┼───── high-risk → к тебе
                      │      (policy gate)        │
                      ▼                          ▼
            ┌───────────────────────────────────────────────┐
            │          ОРКЕСТРАТОР (диспетчер задач)          │
            └───────────────────────────────────────────────┘
                      раздаёт задачи агентам ▼
```

Каждое потенциально «дорогое» действие (исходящее сообщение, звонок, назначение
встречи, смена стадии на WON/LOST, отправка цены, эскалация) агент **предлагает**,
а не выполняет сразу. Политика решает: выполнить автоматически (low-risk) или
поставить тебе в очередь на одобрение (high-risk). Так ты один контролируешь
десятки параллельных диалогов, не делая рутину руками.

## 2. Штат «ИИ-сотрудников» (роли)

| # | Сотрудник | Роль в воронке | Реальный движок |
|---|-----------|----------------|-----------------|
| 1 | **Scout** | Сбор и обогащение лидов (ICP) | парсеры / импорт / enrichment API |
| 2 | **Caller** | Массовый обзвон, голосовой агент | Vapi / Retell / Bland (EN), локальная телефония (RU) |
| 3 | **Messenger** | Диалоги в Telegram / WhatsApp | Telegram Bot API, WhatsApp Cloud API |
| 4 | **Emailer** | Массовая и персональная почта, follow-up | SMTP / Postmark / Resend + warmup |
| 5 | **Qualifier** | Квалификация ЛПР (ICP/BANT), решает next step | Claude (мозг агента) |
| 6 | **Scheduler** | Назначение онлайн-встреч, инвайты, календарь | Google Calendar / Cal.com |
| 7 | **CRM-keeper** | Пишет всё в CRM, двигает по стадиям, дедуп | внутренняя CRM (этот каркас) / HubSpot / Pipedrive / amoCRM |
| 8 | **Analyst** | Метрики, отчёты, «брифы решений» для тебя | Claude (Opus для брифов) |
| 9 | **Dispatcher** | Оркестратор: раздаёт задачи, держит политику MITM | внутренний движок |

«10–20 сотрудников» = эти роли × параллельные инстансы (например, 5 одновременных
голосовых линий + 8 параллельных мессенджер-диалогов).

## 3. Воронка (стадии CRM)

```
NEW ──> CONTACTED ──> ENGAGED ──> MEETING_SET ──> MEETING_DONE ──> WON
  │          │            │             │                            
  └──────────┴────────────┴─────────────┴────────────────────────> LOST / NURTURE
```

Сценарий, который ты описал, ложится на стадии так:

1. **Массовый обзвон / e-mail** → Caller / Emailer → лог в CRM (`CONTACTED`).
2. **Диалог в мессенджере** → Messenger → лог в CRM (`ENGAGED`).
3. **Назначение онлайн-встречи** → Scheduler → лог в CRM (`MEETING_SET`).
   - На встречу: **я приду / клиент сам / пропускаем** — выбираешь ты в карточке одобрения.
4. **Результат встречи** → отмечается в CRM (`MEETING_DONE` → `WON`/`LOST`/`NURTURE`).

## 4. Где именно ты в центре (точки одобрения)

| Шлюз | Что решает система сама | Что уходит к тебе |
|------|-------------------------|-------------------|
| Исходящее сообщение | шаблонный follow-up низкого риска | нестандартный/чувствительный текст |
| Звонок | стандартный скрипт по ICP | звонок крупному аккаунту |
| **Назначение встречи** | предлагает слот | **ты выбираешь: я приду / клиент сам / пропуск** |
| Цена / коммерческое | — | всегда к тебе |
| Стадия WON / LOST | — | всегда к тебе |
| Эскалация (негатив, юрвопрос, крупный чек) | — | всегда к тебе |

Пороги настраиваются в `core/config.py` → `APPROVAL_POLICY`.

## 5. Технологический стек

- **Backend / ядро:** Python + FastAPI, WebSocket (realtime), SQLite → Postgres позже.
- **Мозги агентов:** Anthropic Claude — `claude-sonnet-4-6` для объёма (SDR-диалоги,
  квалификация), `claude-opus-4-8` для брифов решений тебе.
- **Голос:** Vapi / Retell / Bland (EN) + локальная телефония (RU).
- **Мессенджеры:** Telegram Bot API, WhatsApp Cloud API.
- **Почта:** SMTP / Postmark / Resend + прогрев домена.
- **Календарь:** Google Calendar API / Cal.com.
- **CRM:** внутренняя (в этом каркасе) или sync с HubSpot / Pipedrive / amoCRM.
- **Панель:** киберпанк command-center на canvas + WebSocket (этот каркас, `web/`).
- **Триггеры/рутина:** внутренний оркестратор; при желании — n8n для внешних вебхуков.

## 6. Комплаенс (важно для EU + RU)

- **GDPR / 152-ФЗ:** opt-out в каждом сообщении, DNC-список, хранение согласия.
- **Правила обзвона:** рабочие часы по таймзоне контакта, лимиты частоты.
- **Прозрачность:** агент представляется ассистентом; передача «живому» (тебе) по запросу.

Это не юр-консультация — перед боевым запуском обзвона/рассылок сверься с локальными правилами.
