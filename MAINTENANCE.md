## 2026-08-02 — описание API и починка быстрого старта

**Что изменено**

- `README.md` — в «Быстром старте» был путь `cd /Users/alex/NeuroCompany`.
  У всех, кроме автора, такой папки нет: инструкция ломалась на первой же
  строке. Заменено на `git clone` + `cd neuro_company_claude`.
- `README.md` — ссылка на `docs/API.md` рядом со ссылкой на архитектуру.

**Зачем**

`ARCHITECTURE.md` объясняет замысел, README — как запустить, но между ними
не было слоя «как с этим разговаривать программно». А он нужен: сценарий
«лиды приезжают из внешнего источника» и сценарий «одобряю с телефона, а не
из панели» — оба про API, и оба раньше требовали чтения `server.py`.

Отдельно задокументировано неочевидное поведение `resolve`: повторное решение
по уже закрытой карточке возвращает `{"ok": false}` с кодом 200, а не ошибку —
чтобы двойной клик в панели не выглядел как сбой.

**Совместимость**

Код не тронут: изменения только в документации. Правка README чинит команду,
которая до этого работала лишь на машине автора.
